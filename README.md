# ReproX

## Getting Started

### How to install
`npm install`

### How to run
`npm run dev`

### How to build
`npm run build`

### How to run tests
`npm test`

## Regression Decision Flow
- **LOW** → AI Auto-Fix → Verification
- **MEDIUM** → Developer Approval → Fix → Verification
- **HIGH** → Developer Approval → Fix → Verification
- **Protected/Critical** → Developer Approval
